# Referral Program

The Scallop referral program allows veSCA holders to act as referrers. Referees bind their address to a referrer's veSCA key, and the referrer earns a share of the protocol revenue generated by the referee's activity.

## How It Works

1. Referee calls `bindToReferral(veScaKeyId)` to bind their address to a referrer's veSCA key
2. The referrer's veSCA key accumulates revenue share from the referee's lending/borrowing activity
3. Referrer claims revenue using `claimReferralRevenue` or `claimReferralRevenueQuick`
4. Referral tickets can be optionally used for additional claims

## Quick Start

```typescript
import { Scallop } from '@scallop-io/sui-scallop-sdk';

const sdk = new Scallop({
  addressId: '67c44a103fe1b8c454eb9699',
  networkType: 'mainnet',
  secretKey: process.env.SECRET_KEY,
});

const builder = await sdk.createScallopBuilder();
const txBlock = builder.createTxBlock();
txBlock.setSender(myAddress);
```

## Builder Methods (Transaction Operations)

### Normal Methods

#### `bindToReferral(veScaKeyId)`

Bind the sender's address to a referrer's veSCA key. Called by the **referee**.

```typescript
// Bind to referrer's veSCA key ID
txBlock.bindToReferral('0xabc...');

await builder.signAndSendTxBlock(txBlock);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `veScaKeyId` | `string` | The referrer's VeScaKey object ID |

---

#### `claimReferralTicket(poolCoinName)`

Claim a referral ticket for a specific pool coin. Tickets can be burned for additional revenue.

```typescript
const ticket = txBlock.claimReferralTicket('sui');
// Use ticket immediately or transfer it
txBlock.burnReferralTicket(ticket, 'sui');
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `poolCoinName` | `string` | Pool coin name, e.g. `'sui'`, `'usdc'` |

**Returns:** `TransactionResult` (the referral ticket object)

---

#### `burnReferralTicket(ticket, poolCoinName)`

Burn a referral ticket to receive revenue from the referral revenue pool.

```typescript
txBlock.burnReferralTicket(ticket, 'sui');
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `ticket` | `SuiObjectArg` | The referral ticket object |
| `poolCoinName` | `string` | Pool coin name matching the ticket |

---

#### `claimReferralRevenue(veScaKey, poolCoinName)`

Claim accumulated referral revenue for a specific coin. Called by the **referrer**.

```typescript
const revenueCoin = txBlock.claimReferralRevenue(veScaKeyId, 'sui');
txBlock.transferObjects([revenueCoin], sender);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `veScaKey` | `SuiObjectArg` | The referrer's VeScaKey ID |
| `poolCoinName` | `string` | Pool coin name to claim, e.g. `'sui'`, `'usdc'` |

**Returns:** `TransactionResult` (the revenue coin)

---

### Quick Methods

#### `claimReferralRevenueQuick(veScaKey, coinNames?)`

Claim referral revenue for all supported lending coins in one transaction. Automatically merges claimed coins with existing wallet coins.

```typescript
// Claim for all lending coins
await txBlock.claimReferralRevenueQuick(veScaKeyId);

// Claim for specific coins only
await txBlock.claimReferralRevenueQuick(veScaKeyId, ['sui', 'usdc', 'wbtc']);

await builder.signAndSendTxBlock(txBlock);
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `veScaKey` | `SuiObjectArg` | The referrer's VeScaKey ID |
| `coinNames` | `string[]` | (optional) Filter to specific coins; defaults to all lending coins |

---

## Query Methods

### Check Referral Binding

Check which referrer veSCA key a given address is bound to.

```typescript
const query = await sdk.createScallopQuery();

// Check if the connected wallet is bound to a referrer
const referrerVeScaKeyId = await query.getVeScaKeyIdFromReferralBindings();
// Returns: '0x...' if bound, null if not bound

// Check for a specific address
const keyId = await query.getVeScaKeyIdFromReferralBindings('0x...');
```

| Parameter | Type | Description |
|-----------|------|-------------|
| `walletAddress` | `string` | (optional) Address to check; defaults to connected wallet |

**Returns:** `string | null` (the referrer's VeScaKey ID, or null if not bound)

---

## Full Example: Referrer Claims Revenue

```typescript
import { Scallop } from '@scallop-io/sui-scallop-sdk';

const sdk = new Scallop({
  addressId: '67c44a103fe1b8c454eb9699',
  networkType: 'mainnet',
  secretKey: process.env.SECRET_KEY,
});

// Get referrer's veSCA key
const query = await sdk.createScallopQuery();
const veScas = await query.getVeScas();
if (veScas.length === 0) throw new Error('No veSCA found');

const builder = await sdk.createScallopBuilder();
const txBlock = builder.createTxBlock();
txBlock.setSender(myAddress);

// Claim all referral revenue
await txBlock.claimReferralRevenueQuick(veScas[0].keyObject);

await builder.signAndSendTxBlock(txBlock);
```

## Full Example: Referee Binds to Referrer

```typescript
const builder = await sdk.createScallopBuilder();
const txBlock = builder.createTxBlock();
txBlock.setSender(refereeAddress);

// Bind to referrer's veSCA key
txBlock.bindToReferral('0xabc...referrerVeScaKeyId');

await builder.signAndSendTxBlock(txBlock);
```
